# יפן2 — מתכנן טיול דינמי

אפליקציית דף-יחיד (HTML/CSS/JS, ללא build) לתכנון טיול ביפן. הנתונים נשמרים אוטומטית
בדפדפן (localStorage), עם מפת Leaflet, סינון, ועריכה ישירה מתוך הממשק.

## הפעלה
פתחו את `index.html` בדפדפן — זהו. (לחיבור מלא של המפה והפונטים נדרש אינטרנט.)
אם פותחים מהמחשב ישירות (`file://`) זה עובד; אפשר גם להריץ שרת מקומי:
`python3 -m http.server` ואז לגשת ל-`http://localhost:8000`.

## מבנה
```
index.html              שלד הדף + סדר טעינת הסקריפטים
css/styles.css          כל העיצוב (RTL, עברית)
data/
  base-kansai.js        נתוני קנסאי (9 ימים) — אמיתי
  base-hokkaido.js      הוקאידו — שלד ריק, מוכן למילוי
  base-tokyo.js         טוקיו — שלד ריק, מוכן למילוי
  coords-lookup.js      קואורדינטות גיבוי לפי שם מקום
js/
  normalize.js          בניית מודל נקי מהנתונים הגולמיים
  store.js              מצב + שמירה ב-localStorage (איפוס מחזיר לבסיס)
  components.js          עוזרי DOM קטנים
  map.js                מפת Leaflet + סיכות צבעוניות
  filters.js            סרגל סינון + מקרא
  detail.js             חלון פרטים (יום / מקום)
  edit.js               טפסי עריכה
  screens.js            6 המסכים: תכנון · זמנים · מקומות · לינה · עלויות · סיכום
  app.js                איתחול וחיווט הכל
```

## הוספת תוכן
כל יום נשמר לפי ה-schema שב-`japandayschema.json`. כדי להוסיף ימים לאזור חדש,
ערכו את `days` בקובץ ה-`data/` המתאים — והם יופיעו אוטומטית בכל המסכים ובמפה.
מקומות ללא `lat`/`lng` מסומנים באזהרה; אפשר להשלים מיקום דרך כפתור העריכה.
